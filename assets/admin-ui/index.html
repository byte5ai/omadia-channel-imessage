Warte auf die erste authentifizierte Zustellung von Sendblue…

So richtest du Sendblue ein (sendblue.com):

  1. API-Keys: im Sendblue-Dashboard API Key ID und API Secret Key kopieren und im Plugin-Setup hinterlegen.
  2. Absender-Nummer: deine Sendblue-Line (E.164, z.B. +15122164639) als from_number eintragen.
  3. Webhook-Secret: langes Zufallstoken generieren (openssl rand -hex 32) und im Plugin-Setup speichern.
  4. Receive-Webhook: die URL oben (mit deinem Secret als letztem Pfadsegment) im Sendblue-Dashboard als Webhook-URL eintragen.
  5. Sandbox-Hinweis: im Free-Tarif müssen Empfänger die Line zuerst anschreiben, bevor die API sie erreichen darf.
